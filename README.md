# bidama-shiryou

shiryou (資料, materials) is a tree of blue bidamas for data a program declares and keeps: fetched frontend data (toriyose), amendments (shuusei) and template leaves (happa).

`khipu`, blue's knowledge graph, stays in blue's core as a toolchain bidama, because blue's own `arika` command uses it from blue's compiled distribution.

Use a level with `use("shiryou/<level>")` after `source("shiryou", "github:pleme-io/bidama-shiryou", "bidamas")` in your Bluefile. The old names (`use("happa")`) still load through the `legacy_packages` bridge and say how to rewrite them.
